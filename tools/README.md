# Сборка сайта

После любых правок страниц запускайте:

```sh
python3 tools/build_site.py
```

Сборщик сам:

1. **Картинки.** JPG/PNG, на которые ссылаются страницы, превращает в AVIF (длинная сторона до 2560 px) и меняет ссылки. Оригиналы переносит в `.originals/` — эта папка не попадает в git и на сайт. Для `og:image` делает JPEG 1200 px в `images/og/` (соцсети и мессенджеры не понимают AVIF).
2. **Русские страницы** (`*.html` в корне):
   - проставляет `width`/`height` всем картинкам — без них не работает ленивая загрузка;
   - пишет `alt` картинкам без него («Название проекта, изображение N»; `alt=""` означает «декоративная» и не трогается);
   - описание страницы: если у `<meta name="description">` стоит `data-auto` (или описание ещё стандартное), оно собирается из первого абзаца или из заголовка и подписи. Чтобы написать описание вручную — впишите его и удалите `data-auto`;
   - `og:*`, `canonical`, `hreflang`, скрытый `h1` на страницах без заголовка;
   - вставляет шапку и подвал из `partials/` прямо в HTML.
3. **Английская версия** в `en/` — машинный перевод с кэшем `.cache/ru_en_translation.json`. Чтобы поправить перевод, исправьте значение в кэше и пересоберите.
4. `sitemap.xml` и `robots.txt`.

Без интернета: `python3 tools/build_site.py --offline` — английский собирается только из кэша, непереведённые строки выводятся списком.

## Новая страница

1. Скопируйте шаблон: `project-blanck.html` (проект), `article-blanck.html` (заметка) или `video-blanck.html` (видео).
2. Поправьте `<title>` и тексты (адреса, `og:*`, шапку и подвал сборщик проставит сам); картинки кладите в `images/…` в любом формате.
3. Добавьте карточку в `portfolio.html` / `articles.html` / `video.html`. В портфолио у карточки должен быть `data-tag="…"` — это тег для фильтра.
4. `python3 tools/build_site.py`.

## Зависимости

```sh
python3 -m pip install -r tools/requirements.txt
```
