# nikitanova.com на Astro

```sh
npm install        # один раз
npm run dev        # сайт на http://localhost:4321 с живым обновлением
npm run build      # проверка + сборка в dist/
npm run preview    # посмотреть собранный dist/
```

## Где что лежит

- `src/content/projects/<адрес>/index.md` — проект: данные сверху (между `---`), текст снизу, картинки в той же папке. Адрес страницы — имя папки: `wibes/` → `/wibes.html`.
- `src/content/notes/<адрес>/index.md` — заметка: заголовок и дата сверху, текст в Markdown.
- `src/content.config.ts` — какие поля бывают у проекта и заметки и список тегов портфолио. Если в проекте опечатка в теге или не хватает картинки, сборка остановится и скажет, где ошибка.
- `src/pages/` — страницы: главная, портфолио, заметки, «Обо мне», 404, sitemap.
- `src/layouts/`, `src/components/` — общий шаблон, шапка, подвал, галерея, карточка проекта.
- `src/styles/` — стили (дизайн-система IDS и стили сайта).
- `public/` — файлы как есть: видео, иконка, robots.txt.

## Новый проект

1. Создать папку `src/content/projects/<адрес>/`, положить туда картинки (JPG, PNG или AVIF в полном размере — Astro сам сделает уменьшенные версии и AVIF/WebP).
2. Создать `index.md`:

```md
---
title: "Название проекта"
tag: "графика"          # один из тегов в src/content.config.ts
order: 45               # место в портфолио: меньше — выше
card:
  size: L               # M, L или XL — ширина карточки
  cover: ./cover.jpg
galleries:
  - - image: ./1.jpg
      size: XL          # на всю ширину галереи
    - image: ./2.jpg
---

Задача: …

Сделано в 2026 году
```

- `hidden: true` — убрать проект с сайта (страница останется по ссылке, но без индексации).
- `soon: true` — карточка без страницы («скоро»).
- `cardTitle` — если на карточке название другое, чем на странице.
