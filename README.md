# novanikita.github.io

Сайт на [Astro](https://astro.build). Публикуется на GitHub Pages сам: после `git push` в `main` GitHub собирает сайт и выкладывает его (вкладка Actions в репозитории).

```sh
npm install        # один раз (нужен Node 24: nvm install 24)
npm run dev        # сайт на http://localhost:4321, обновляется при правках
npm run build      # проверка + сборка в dist/
npm run preview    # посмотреть собранный dist/
```

В режиме `dev` картинки нарезаются при первом открытии страницы, поэтому большие галереи и портфолио в первый раз грузятся медленно. В собранном сайте такого нет.

## Где что лежит

| Папка | Что там |
|---|---|
| `src/content/projects/<адрес>/` | проекты портфолио |
| `src/content/notes/<адрес>/` | заметки |
| `src/content/videos/<адрес>/` | видео |
| `src/content/travels/<адрес>/` | путешествия |
| `src/content/meetups/<адрес>/` | дизайн-воскресенья |
| `src/content.config.ts` | какие поля бывают у каждой записи и список тегов портфолио |
| `src/pages/` | адреса страниц; `about.astro` и `consultation.astro` — тексты «Обо мне» и «Консультаций» |
| `src/views/`, `src/layouts/`, `src/components/` | шаблоны разделов и страниц, шапка, подвал, галерея, карточка |
| `src/lib/i18n.ts` | подписи интерфейса на двух языках |
| `src/lib/site.ts` | скрытые разделы |
| `src/styles/` | стили (дизайн-система IDS и стили сайта) |
| `public/` | файлы как есть: видео, иконка, robots.txt, CNAME |

Каждая запись — папка: `index.md` (данные между `---` сверху, текст ниже) и картинки рядом. Имя папки — адрес страницы: `wibes/` → `/wibes.html` и `/en/wibes.html`. Если в записи опечатка в теге, нет нужного поля или картинки, сборка остановится и скажет, где ошибка.

## Новый проект

1. Папка `src/content/projects/<адрес>/`, в неё картинки в полном размере (JPG, PNG или AVIF) — уменьшенные версии, AVIF и запасной WebP сделаются сами.
2. `index.md`:

```md
---
title: "Название проекта"
tag: "графика"          # один из тегов в src/content.config.ts
order: 45               # место в портфолио: меньше — выше; шаг 10 оставляет место для новых
card:
  size: L               # M, L или XL — ширина карточки
  cover: ./cover.jpg
galleries:              # группы картинок; между группами большой отступ
  - - image: ./1.jpg
      size: XL          # на всю ширину галереи
    - image: ./2.jpg
---

Задача: …

Сделано в 2026 году
```

3. `en.md` рядом — английский текст:

```md
---
title: "Project name"
---

Task: …

Made in 2026
```

Без `en.md` английская страница покажет русский текст и не будет индексироваться.

Ещё поля: `hidden: true` — убрать проект с сайта (страница останется по ссылке, без индексации); `soon: true` — карточка без страницы; `cardTitle` — другое название на карточке; `textSize: normal` — текст обычного размера вместо мелкого; `description` — своё описание для поисковиков и превью ссылок (по умолчанию берётся из текста).

## Заметки

`src/content/notes/<адрес>/index.md`: `title`, `order`, `meta` (строки курсивом под заголовком), текст в Markdown, картинки — `![подпись](./картинка.jpg)`. Если в заметке нужны галереи, файл называется `index.mdx`, пример — `how-did-designers-come-about/`.

## Скрыть или вернуть раздел

«Видео» и «Путешествия» сейчас скрыты: их нет в меню, страницы открываются по ссылке, но не индексируются. Вернуть — убрать раздел из `src/lib/site.ts` и добавить пункт в меню в `src/components/Header.astro`.

## Публикация

`.github/workflows/deploy.yml` собирает и выкладывает сайт при каждом пуше в `main`. Нарезанные картинки кэшируются между сборками, так что выкладка занимает пару минут; первая — дольше. В настройках репозитория (Settings → Pages) источником должен быть выбран «GitHub Actions».
